**Daily To-Do — UI/UX Case Study
**
A UI/UX case study for a Daily To-Do task management app designed to help users plan their day, manage priorities, set reminders, track progress, and stay consistent with their goals.

**Project Overview**

The Daily To-Do app focuses on making everyday task management simple, clear, and efficient. The design combines task planning, reminders, categories, progress tracking, habit tracking, and focus time into one streamlined experience.

**Problem**

Users commonly face challenges such as:

- Forgetting daily tasks
- Difficulty managing multiple tasks
- Lack of clear task priorities
- Missing reminders
- No integrated habit tracking
- Confusing task management interfaces

**Solution**

The app introduces:

- Smart reminders with snooze
- Priority tags and filters
- Habit and streak tracking
- Weekly overview
- Task categories
- Calendar-based task planning
- Focus Time using the Pomodoro technique
- Personalized user experience

**UX Process
**
The project follows a Design Thinking approach:

1. Empathize
2. Define
3. Ideate
4. Design
5. Testing

**UI Design**

The final interface includes:

- Splash Screen
- Sign Up & Login
- Home Screen
- Calendar
- Task Creation
- Task Details
- Categories
- Notifications
- Profile
- Focus Mode
- Streak Tracking
- Personalization
- Settings

The design system uses Inter typography along with a purple, orange, white, dark, and grey color palette.
